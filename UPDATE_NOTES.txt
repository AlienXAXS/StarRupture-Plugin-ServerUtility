- ServerUtility now takes its game values (function addresses and member offsets) from the mod loader's version object map (the version map), so the same DLL runs on every supported server build. The plugin no longer carries values of its own. If the loader has no row for one of the engine members behind a single feature (the player list, admin player actions, the gatherable relevancy fix, the RCON save command or player lookup), that feature is switched off and ModLoader.log says which. If it has no row for anything else the plugin needs, the plugin is refused and ModLoader.log says why ("will NOT be loaded"). Needs ModLoader 1.27.0 or newer (plugin interface 79).
- The auto-profession patch that goes with Max Players now reads the Soldier value from the game's own data instead of a fixed number. If the game build has no such entry, the patch stays off and the log says so.
- The RCON player list now uses the world the mod loader supplies, which stays right after a game update, and is refreshed on the game thread instead of a background thread.
